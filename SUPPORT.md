# Support

## Where to Ask for Help

- Use GitHub Discussions for setup help, usage questions, architecture discussion, and roadmap conversations.
- Use GitHub Issues for reproducible bugs and concrete feature requests.
- Use the docs in this repository for setup and operations details before opening a thread.

## Issue Routing

- Bug: use the bug report template
- Feature request: use the feature request template
- Security issue: follow [SECURITY.md](./SECURITY.md)
- Conduct concern: follow [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)

## What Helps Most

The fastest way to get useful help is to include:

- deployment mode: local or Docker Compose
- OS, Python, and Node versions
- model provider type and execution target
- relevant logs, artifact paths, or screenshots
- exact reproduction steps
